# 성장원장 (Growth Ledger)

서비스기획자를 사업·조직 리더로 키우는 개인용 자기훈련 원장. 실무(딜·의사결정·위임)를 기록하면 사업감각과 리더십이 숫자로 남는다.

- 개인 프로젝트(1인 사용) · 클라이언트 전용 · 백엔드 없음
- 데이터는 브라우저 localStorage에만 저장 → 상단 "내보내기/가져오기"로 JSON 백업
- 스택: Vite + React + react-router · 배포: Vercel(git push 자동)

## 핵심 기능

- 사업성 머니테스트 (히어로): 쉬운 질문 몇 개 → 회수기간·ROI·순절감 자동계산 → 신호등 판정 + 영업 근거문장. 모르는 값은 '추정'으로 두고 정직하게 노랑에서 멈춘다.
- 딜 파이프라인: 표 + 가중금액(예상액×확률) + 다음행동 없는 딜 경고(rotting)
- 주간 자기리뷰: 직접 푼 문제 vs 남이 풀게 만든 문제(사람·AI·외주·자동화) → 북극성 비율
- 성장: 역량 5영역 자가진단

## 개발

```
npm install
npm run dev      # 로컬 개발
npm run build    # 프로덕션 빌드(dist)
```

배포: `ship .` (Vercel 재배포).
